This project is a simple Python script that demonstrates basic file handling and data processing. The script reads data from a text file, processes it, and outputs the results to another file. The main function of this project is to store and manage a database of Songs in my music record collection. The script allows users to add new songs, view existing songs, and search for specific songs based on various criteria such as title, artist, or genre.

This project is still in working progress, and I plan to add more features in the future, such as the ability to delete songs, update song information, and sort the song list based on different attributes. Additionally, I aim to implement a graphical user interface (GUI) to make the application more user-friendly.
